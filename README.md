# PigGod

Minecraft **Paper 1.21.11** 插件  
指令：`/piggod`（别名：`/猪神`、`/pgod`）

参考 B 站 **Pig God（猪神）** 梗制作。

## 功能

- 在玩家身边召唤一只发光、无敌的「猪神」
- 播放梗风格来电消息（还我十万美刀 / Dream die die die 等）
- 粒子 + 音效效果

## 使用方法

1. 用 Maven 编译：`mvn clean package`
2. 把 `target/PigGod-1.0.0.jar` 放入服务器 `plugins` 文件夹
3. 重启服务器
4. 游戏内输入 `/piggod`

## 权限

- `piggod.use`（默认所有人可用）
